# Dress-Code: the standard DressCode enforces

Generated by `dresscode standard`. It says what DressCode enforces, which is a part of a
coding standard, not the whole of it: what no rule covers is not here.

- Composed of: `dresscode/psr12`, `dresscode/per`, `dresscode/nette`
- Indentation: a tab
- Line ending: the one each file mostly has
- Written for PHP 8.4

153 rules are enforced.

## Arrays

### dresscode/short-array-syntax

Writes arrays and destructuring with the short syntax.


### dresscode/trailing-comma

Puts the trailing comma into a multi-line list and removes it from a one-line one.

As this project has it: `multiLine`: `["arrays","arguments","parameters"]`.


### dresscode/multi-line-array

Puts every item of a multi-line array on its own line and the opening bracket on the line before.

As this project has it: `oneItemPerLine`: `false`.


### dresscode/array-spacing

Removes whitespace inside the brackets of an array.


## Classes

### dresscode/name-casing

Reports declared names that do not follow the case convention configured for their kind.

As this project has it: `classes`: `PascalCase`, `methods`: `camelCase`, `constants`: `PascalCase`, `enumCases`: `PascalCase`, `functions`: `camelCase`, `properties`: `camelCase`, `variables`: `camelCase`.


### dresscode/class-definition-spacing

Puts single spaces in the head of a class declaration.

As this project has it: `spaceBeforeParenthesis`: `true`.


### dresscode/ordered-members

Orders class members by kind and visibility.

As this project has it: `order`: `["use_trait","constant","constant_public","constant_protected","constant_private","property_public","property_protected","property_private"]`.


### dresscode/visibility-required

Requires visibility on class members and orders their modifiers.


### dresscode/single-member-per-declaration

Splits a declaration of several constants, properties or traits into one per member.

As this project has it: `members`: `["property","trait"]`.


### dresscode/single-member-per-line

Puts every member of a class on its own line.


### dresscode/useless-modifier

Removes a member modifier the class already implies.


### dresscode/useless-null-property-initialization

Removes the explicit null initialization of untyped properties.


### dresscode/self-for-current-class

Replaces the name of the current class with self.


### dresscode/modern-class-name-reference

Uses ::class instead of get_class() and __CLASS__.

As this project has it: `onObjects`: `true`.


### dresscode/no-this-in-static-context

Reports $this used where no object is available.


### dresscode/final-internal-class

Makes classes annotated as internal final.


### dresscode/no-kind-in-class-name

Reports a class, interface or trait name repeating its kind.
