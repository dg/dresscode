## The rules

### dresscode/annotation-name

Writes known annotations in their canonical case.

Stage: Structure. Modifies comments.

### dresscode/array-spacing

Removes whitespace inside the brackets of an array.

Stage: Formatting.

### dresscode/arrow-function

Replaces a closure returning a single expression with an arrow function.

Stage: Structure.

| Option | Type | Default | |
|---|---|---|---|
| `allowNested` | bool | `true` | A closure containing another closure or arrow function is converted too |

### dresscode/attribute-after-phpdoc

Moves a doc comment written after the attributes above them.

Stage: Structure. Modifies comments.

### dresscode/attribute-position

Puts the attributes of a declaration on lines of their own above it.

Stage: Formatting.

### dresscode/attribute-spacing

Removes whitespace inside the brackets of an attribute group.

Stage: Formatting.

### dresscode/binary-operator-spacing

Puts spaces around binary operators.

Stage: Formatting.

| Option | Type | Default | |
|---|---|---|---|
| `alignment` | `none` \| `spaces` \| `tabs` \| `keep` | `"spaces"` | Which alignment around an operator stays: none collapses it to a single space, spaces and tabs keep the one written with them, keep keeps any |

### dresscode/blank-lines

Puts blank lines where the standard asks for them, in the header, the class, the block and between statements.

Stage: Formatting.

| Option | Type | Default | |
|---|---|---|---|
| `afterOpeningTag` | int \| [int, ?int] | `1` | After the line of &lt;?php, which then carries no code; a file with markup outside PHP keeps its tag |
| `beforeNamespace` | int \| [int, ?int] | `1` | Before the namespace declaration |
| `afterNamespace` | int \| [int, ?int] | `1` | After an unbraced namespace declaration |
| `afterImports` | int \| [int, ?int] | `1` | After the last import, before the rest of the code |
| `betweenImportGroups` | int \| [int, ?int] | `1` | Between imports of classes, functions and constants; imports of one group never have a blank line between them |
| `beforeDeclaration` | int \| [int, ?int] | `"keep"` | Before a class, interface, trait, enum or function that follows the namespace or the imports, in place of afterNamespace and afterImports |
| `betweenDeclarations` | int \| [int, ?int] | `2` | Before and after a class, interface, trait, enum or function declared among statements, where the header above it does not decide |
| `betweenMethods` | int \| [int, ?int] | `2` | Before and after a method; the first and last method of a class use beforeFirstMethod and afterLastMethod |
| `betweenMethodsInInterface` | int \| [int, ?int] | `1` |  |
| `beforeFirstMethod` | int \| [int, ?int] | `0` | Before a method that is the first member of its class |
| `afterLastMethod` | int \| [int, ?int] | `0` | After a method that is the last member of its class |
| `afterClassBrace` | int \| [int, ?int] | `0` | Before the first member, unless it is a method: then beforeFirstMethod applies |
| `beforeClassBrace` | int \| [int, ?int] | `0` | After the last member, unless it is a method: then afterLastMethod applies |
| `betweenTraitUses` | int \| [int, ?int] | `0` |  |
| `afterTraitUses` | int \| [int, ?int] | `1` | Before the member following the trait uses, unless it is a method: then betweenMethods applies |
| `betweenMembers` | int \| [int, ?int] | `[0,1]` | Between properties, constants and enum cases without a doc comment or attribute |
| `beforeDocumentedMember` | int \| [int, ?int] | `1` | Before a property, constant or enum case with a doc comment or an attribute |
| `afterPhpDoc` | int \| [int, ?int] | `0` | Between a doc comment or an attribute and the declaration it belongs to |
| `afterBlockBrace` | int \| [int, ?int] | `0` | After the opening brace of a block |
| `beforeBlockBrace` | int \| [int, ?int] | `"keep"` | Before the closing brace of a block; kept by default, because such a line separates the branches of a } catch or } else chain |
| `before` | array | `{"return":[1,null]}` | Blank lines before a statement of the kind, as a count or a range [min, max] with null for no bound; yield means a statement made of a yield expression |
| `after` | array | `[]` | Blank lines after a statement of the kind, before the next statement |

### dresscode/braces-position

Positions the braces of classes, functions and control structures, and the keywords between them.

Stage: Formatting.

| Option | Type | Default | |
|---|---|---|---|
| `multiLineParameters` | `sameLine` \| `nextLine` \| `nextLineAfterReturnType` | `"sameLine"` | Brace of a function whose parameters span several lines; nextLineAfterReturnType puts it on the next line only when there is a return type |
| `classes` | `sameLine` \| `nextLine` | `"nextLine"` | Classes, interfaces, traits and enums |
| `anonymousClasses` | `sameLine` \| `nextLine` | `"sameLine"` |  |
| `anonymousFunctions` | `sameLine` \| `nextLine` | `"sameLine"` |  |
| `controlStructures` | `sameLine` \| `nextLine` | `"sameLine"` |  |
| `singleLineAnonymousFunctions` | `allowed` \| `expanded` | `"allowed"` | A closure written whole on one line: allowed leaves it there, expanded gives its braces the position of any other |
| `emptyAnonymousClasses` | `sameLine` \| `ownLine` | `"sameLine"` | An empty anonymous class as {} on the line of new, whatever it holds inside |
| `emptyBodies` | `sameLine` \| `ownLine` | `"ownLine"` | An empty body of a class, function, method or closure as {} on the line of its head; a comment inside makes it not empty |
| `continuation` | `sameLine` \| `nextLine` | `"sameLine"` | The keyword continuing a structure (else, elseif, catch, finally, the while of do) on the line of the closing brace, or on the next one |

Puts single spaces in the head of a class declaration.

Stage: Formatting.

| Option | Type | Default | |
|---|---|---|---|
| `beforeParenthesis` | `single` \| `none` | `"single"` | Between class and the arguments of an anonymous class: single writes new class ($a), none hugs them |

### dresscode/class-reference-name-casing

Stage: Structure.

### dresscode/combined-assignment-operator

### dresscode/combined-issets

Asks about several variables in one isset() instead of a chain joined by &&.

Stage: Structure.

### dresscode/combined-unsets

Drops several variables in one unset instead of consecutive statements.

Stage: Structure.

### dresscode/comma-spacing

Puts a single space after a comma and none before it.

Stage: Formatting.

| Option | Type | Default | |
|---|---|---|---|
| `alignment` | `none` \| `spaces` \| `tabs` \| `keep` | `"tabs"` | Which alignment after a comma stays: none collapses it to a single space, spaces and tabs keep the one written with them, keep keeps any |

### dresscode/comment-spacing

Puts a space after the marker of a comment and before a comment following code.

Stage: Cleanup. Modifies comments.

| Option | Type | Default | |
|---|---|---|---|
| `before` | `atLeastSingle` \| `single` \| `keep` | `"atLeastSingle"` | Whitespace before a comment following code on its line: atLeastSingle keeps a wider gap such as an alignment, single collapses it to one space, keep leaves it alone |

### dresscode/commented-out-function

Comments out statements calling the configured debugging functions.

Stage: Structure. Modifies comments. Every fix may change what the code does, so it is made once the rule is named in `fixRisky` or with `--fix-risky`.

| Option | Type | Default | |
|---|---|---|---|
| `functions` | list of string | `["print_r","var_dump","var_export"]` |  |
