## The rules

### dresscode/annotation-name

Writes known annotations in their canonical case.

Stage: Structure. Covers: `SlevomatCodingStandard.Commenting.AnnotationName`. Modifies comments.

### dresscode/array-indentation

Indents the items of a multi-line array one level deeper than its opening line.

Stage: Formatting. Covers: `array_indentation`, `SlevomatCodingStandard.Arrays.MultiLineArrayEndBracketPlacement`. Modifies comments.

### dresscode/array-spacing

Removes whitespace inside the brackets of an array.

Stage: Formatting. Covers: `trim_array_spaces`, `SlevomatCodingStandard.Arrays.SingleLineArrayWhitespace`.

### dresscode/arrow-function

Replaces a closure returning a single expression with an arrow function.

Stage: Structure. Covers: `SlevomatCodingStandard.Functions.RequireArrowFunction`.

| Option | Type | Default | |
|---|---|---|---|
| `allowNested` | bool | `true` | A closure containing another closure or arrow function is converted too |

### dresscode/attribute-after-phpdoc

Moves a doc comment written after the attributes above them.

Stage: Structure. Covers: `SlevomatCodingStandard.Attributes.RequireAttributeAfterDocComment`. Modifies comments.

### dresscode/attribute-spacing

Removes whitespace inside the brackets of an attribute group and the empty parentheses of an attribute.

Stage: Formatting. Covers: `attribute_block_no_spaces`, `attribute_empty_parentheses`, `SlevomatCodingStandard.Attributes.DisallowMultipleAttributesPerLine`.

| Option | Type | Default | |
|---|---|---|---|
| `groupPerLine` | bool | `false` | A #[...] group following another one on its line moves to a line of its own |

### dresscode/binary-operator-spacing

Puts spaces around binary operators.

Stage: Formatting. Covers: `binary_operator_spaces`, `Squiz.WhiteSpace.LogicalOperatorSpacing`, `Squiz.WhiteSpace.OperatorSpacing`.

| Option | Type | Default | |
|---|---|---|---|
| `spacing` | `atLeastSingle` \| `single` | `"atLeastSingle"` | atLeastSingle keeps extra spaces that align assignments or array items, single collapses them to one |

### dresscode/body-blank-lines

Removes the blank line after the opening brace of a block.

Stage: Cleanup. Covers: `Squiz.WhiteSpace.ControlStructureSpacing`, `Squiz.WhiteSpace.FunctionOpeningBraceSpace`.

| Option | Type | Default | |
|---|---|---|---|
| `beforeClosingBrace` | bool | `false` | The blank line before the closing brace goes too |

### dresscode/braces-position

Positions the braces of classes, functions and control structures.

Stage: Formatting. Covers: `Nette/braces_position`, `braces_position`, `PSR2.Classes.ClassDeclaration`, `Squiz.Functions.MultiLineFunctionDeclaration`.

| Option | Type | Default | |
|---|---|---|---|
| `multiLineParameters` | `sameLine` \| `nextLine` \| `nextLineAfterReturnType` | `"sameLine"` | Brace of a function whose parameters span several lines; nextLineAfterReturnType puts it on the next line only when there is a return type |
| `classes` | `sameLine` \| `nextLine` | `"nextLine"` | Classes, interfaces, traits and enums |
| `anonymousClasses` | `sameLine` \| `nextLine` | `"sameLine"` |  |
| `anonymousFunctions` | `sameLine` \| `nextLine` | `"sameLine"` |  |
| `controlStructures` | `sameLine` \| `nextLine` | `"sameLine"` |  |
| `allowSingleLineAnonymousFunctions` | bool | `true` |  |
| `emptyAnonymousClasses` | `sameLine` \| `ownLine` | `"sameLine"` | An empty anonymous class as {} on the line of new, whatever it holds inside |
| `emptyBodies` | `sameLine` \| `ownLine` | `"ownLine"` | An empty body of a class, function, method or closure as {} on the line of its head; a comment inside makes it not empty |

### dresscode/cast-canonical-type

Writes a cast with the short type name in lowercase.

Stage: Structure. Covers: `lowercase_cast`, `short_scalar_cast`, `SlevomatCodingStandard.PHP.TypeCast`, `Squiz.WhiteSpace.CastSpacing`.

### dresscode/cast-spacing

Puts a single space between a cast and its operand.

Stage: Formatting. Covers: `cast_spaces`.

| Option | Type | Default | |
|---|---|---|---|
| `spacing` | `single` \| `none` | `"single"` | Between the cast and its operand |

### dresscode/chain-indentation

Indents the object operators of a multi-line chain one level deeper than the start of the chain.

Stage: Formatting. Covers: `method_chaining_indentation`, `PEAR.WhiteSpace.ObjectOperatorIndent`.

| Option | Type | Default | |
|---|---|---|---|
| `allowNesting` | bool | `false` | A link may stand one level deeper than the link before it, which is how a sub-chain shows that its calls act on what that link returned, and one level shallower to come back out |

### dresscode/class-definition-spacing

Puts single spaces in the head of a class declaration.

Stage: Formatting. Covers: `class_definition`, `PSR2.Classes.ClassDeclaration.SpaceBeforeKeyword`.

| Option | Type | Default | |
|---|---|---|---|
| `spaceBeforeParenthesis` | bool | `true` | Between class and the arguments of an anonymous class: new class ($a), false hugs them |

### dresscode/class-reference-name-casing

Writes the names of internal classes and interfaces in their declared case.

Stage: Structure. Covers: `class_reference_name_casing`.

### dresscode/combined-assignment-operator

Uses += and friends where an assignment repeats its target.

Stage: Structure. Covers: `assign_null_coalescing_to_coalesce_equal`, `SlevomatCodingStandard.ControlStructures.RequireNullCoalesceEqualOperator`, `SlevomatCodingStandard.Operators.RequireCombinedAssignmentOperator`.

### dresscode/combined-issets

### dresscode/combined-unsets

Drops several variables in one unset instead of consecutive statements.

Stage: Structure. Covers: `combine_consecutive_unsets`.

### dresscode/comma-spacing

Puts a single space after a comma and none before it.

Stage: Formatting. Covers: `no_whitespace_before_comma_in_array`, `whitespace_after_comma_in_array`, `Generic.Functions.FunctionCallArgumentSpacing`, `Squiz.Functions.FunctionDeclarationArgumentSpacing`.

| Option | Type | Default | |
|---|---|---|---|
| `tabAlignment` | bool | `true` | Whitespace with a tab after a comma stays, as it aligns columns |

### dresscode/comment-spacing

Puts a space after the marker of a comment and before a comment following code.

Stage: Cleanup. Covers: `PhpCsFixerCustomFixers/comment_surrounded_by_spaces`, `single_line_comment_spacing`. Modifies comments.

| Option | Type | Default | |
|---|---|---|---|
| `before` | ?`atLeastSingle` \| `single` | `"atLeastSingle"` | Whitespace before a comment following code on its line: atLeastSingle keeps a wider gap such as an alignment, single collapses it to one space, null leaves it alone |

### dresscode/commented-out-function

Comments out statements calling the configured debugging functions.

Stage: Structure. Covers: `PhpCsFixerCustomFixers/commented_out_function`. Modifies comments.

| Option | Type | Default | |
|---|---|---|---|
| `functions` | list of string | `["print_r","var_dump","var_export"]` |  |
