DressCode
=========

DressCode checks and fixes PHP coding style, and upgrades code to newer PHP. It parses source files into a lossless concrete syntax tree in which every token, whitespace and comment is preserved, so that rules edit the tree and the printer reproduces the file byte for byte. A configuration says how the code is written, decision by decision; rules, presets and analyses come from plugins, and DressCode itself has no opinion about style.

**Status: in development.** Nothing is usable yet; the API, names and behavior are all subject to change.
